# tiny-stack-vm

A tiny stack VM for make.fun's "Build a tiny stack virtual machine" bounty: one `main.ts` (Node 22, stdlib only) that runs all 40 instances of a set and writes each program's stdout and exit code, implementing the ISA exactly — 32-bit wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their exit codes.
